# A1 白穹纪元 · 执行方案

> 硬性条件：RTX 4090 / 64GB / Windows / 已有 ComfyUI + SD WebUI + ZBrush + Substance Painter
> 时间预算：全职上班，晚上+周末干

---

## 总体路线

```
Phase 0 ─→ Phase 1 ─→ Phase 2 ─→ Phase 3
准备环境    概念图      3D资产      可玩原型
  2天        2周         4周         6周
```

**核心原则：先出图，再建模，最后拼原型。** 每一步产出都可独立展示。

## Phase 0：环境准备（2 天）

### 0.1 装 ComfyUI（你之前想学）
你已经有 SD WebUI 了，但 ComfyUI 做工作流更灵活，出图质量可控。

**方法：**
```
1. 下载 ComfyUI 整合包（B 站搜 "ComfyUI 整合包" 或去 GitHub 下）
2. 解压到 D 盘，双击 run_nvidia_gpu.bat 启动
3. 下载关键模型放进 ComfyUI/models/checkpoints/
```

**关键模型（全免费，跑在 4090 上绰绰有余）：**
| 模型 | 用途 | 下载 |
|------|------|------|
| **Flux.1-dev** | 最高质量概念图 | huggingface 或国内镜像 |
| **SDXL** | 角色/场景通用 | civitai.com |
| **Juggernaut XL** | 写实风格 | civitai.com 评分最高 |
| **DreamShaper XL** | 美术风格 | civitai.com |

### 0.2 装 ControlNet / IP-Adapter
- **ControlNet Canny/OpenPose**：控制人物姿态
- **IP-Adapter**：风格迁移（拿一张已有图统一所有产出风格）

### 0.3 找个参考图集做 moodboard（1 天）
去 Pinterest / ArtStation 搜：
- "dieselpunk architecture"
- "steampunk machinery concept"
- "retro futurism CRT"
- "vacuum tube electronics"

⚠️ 只做参考贴图，别商用。建一个 `07-美术视觉\_references\` 文件夹存参考。

### 1.2 出图工作流

**用 ComfyUI 的最简流程（新手友好）：**

```
输入提示词 → Flux/SDXL 生成 → ControlNet 精修 → 高清放大 → 出图
```

**提示词公式：**
```
[角色描述], mechanical cyberpunk style, exposed gears, hydraulic tubes, 
brass circuit boards, CRT displays, steam pipes, vacuum tube electronics, 
dieselpunk, intricate machinery, photorealistic, volumetric lighting, 
8k, cinematic lighting --ar 3:4

Negative: biopunk, nanopunk, sleek, minimalist, organic, neon glow, 
cyberpunk 2077 style, night city, hologram
```

**实操步骤（以洛安为例）：**
1. 写第一版提示词 → 跑 4 张
2. 挑最接近的一张 → 用 ControlNet 精修姿态/构图
3. HD 放大（x4 Upscale）
4. 扔进 PS/Clip Studio 手动修手/脸
5. 定稿

### 1.3 风格统一技巧

所有角色要看起来是**同一个世界的人**。方法：
- 用 IP-Adapter 把第一张满意的图当"风格锚点"
- 后续所有角色 + 场景都用同一个 LoRA 模型微调
- 光影方向统一（铁锈带用暖锈色光，白穹城用冷白光）

| 任务 | 推荐工具 | 费用 | 理由 |

## Phase 2：3D 资产制作（4 周）

这是你的专业领域，我只给建议。

### 2.1 优先级

先做一个垂直切片用的最小集：

| 资产 | 类型 | 优先级 | 说明 |
|------|------|--------|------|
| 洛安（低模） | 角色 | P0 | 游戏内角色 |
| 标准公寓室内 | 场景 | P0 | 第一章场景 |
| CRT 终端 | 道具 | P0 | UI 交互对象 |
| 通勤列车内景 | 场景 | P1 | 第二章场景 |
| 铁砧工坊 | 场景 | P1 | 铁锈带核心场景 |

### 2.2 你的工具链

```
建模：ZBrush（高模）→ Maya/Blender（拓扑）→ 已有
UV：RizomUV                               → 已有
贴图：Substance Painter                    → 已有
渲染：Marmoset / KeyShot                  → 已有
导入引擎：FBX → Unity/Unreal              → 
```

### 2.3 风格指南（给建模用）

从概念图阶段转 3D 时的关键约束：
- 所有机械结构**必须有功能逻辑**——管线要连着该连的地方
- 颜色限制在白、灰、黄铜、锈红、暗绿五色系内
- 无光滑表面、无碳纤维纹理、无白色发光二极管
- 所有的"屏幕"都做成 CRT 风格——绿色字符、扫描线、屏幕弧度

## Phase 3：可玩原型（6 周）

### 3.1 引擎选型

| 引擎 | 适合 | 你的优势 |
|------|------|---------|
| **Unreal Engine 5** | 画质天花板，适合展示 | 3D 美术已熟悉 |
| Unity | 开发效率高 | 需要学 C# |

**推荐：Unreal Engine 5**（你已经有 3D 经验，蓝图不用写代码）

这样你的路径是：
```
ZBrush 高模 → Substance 贴图 → UE5 蓝图拼场景 → 可玩
```

### 3.2 垂直切片范围

做第一章"不眠之夜"的可玩版本（约 15 分钟体验）：

**需要的功能：**
- 第三人称/第一人称漫游白穹城公寓
- CRT 终端交互（看通告、查积分）
- 脑机接口界面（思想评分 UI）
- 环境叙事（窗外信号塔闪光、管道声音）

**不需要的功能（第一期砍掉）：**
- ❌ 战斗系统
- ❌ PVP
- ❌ 制造采集
- ❌ 家园系统
- ❌ 帮派系统

### 3.3 UE5 学习路径（如果你不熟）

```
Day 1-3: 蓝图基础（创建 Actor、蓝图通信）
Day 4-7: 场景搭建（导入 FBX、光照、PostProcess）
Day 8-14: 交互逻辑（按键检测、UI 制作、对话系统）
Day 15-21: 第一章拼装
Day 22-30: 打磨（光影、音效、过渡动画）
```

### 3.4 垂直切片里程碑

| 周 | 里程碑 | 可交付物 |
|---|--------|---------|
| W1 | 角色+场景低模完成 | 洛安+公寓 FBX |
| W2 | UE5 基础场景搭建 | 可走动的 3D 公寓 |
| W3 | 终端交互完成 | 可点击查看通告 |
| W4 | UI 框架 + 对话系统 | 思想评分界面 |
| W5 | 第一章完整流程打通 | 从起床到看完通告 |
| W6 | 打磨+音效 | 可演示版本 |
