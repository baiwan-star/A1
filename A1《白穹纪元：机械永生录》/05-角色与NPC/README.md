## 设计原则

- 没有"好人"和"坏人"——每个角色在自己的立场上都有合理动机
- 每个角色都服务于"精密窒息"的核心情感体验
- NPC的视觉设计均有对应美术文件（见 `07-美术视觉\角色美术\`）
