# 灰羽 角色档案

- **身份/职务**：锈网（铁锈带地下通信网络）的构建者和运营者。曾是统合部外围通讯系统维护技术员，在发现路由数据指向白穹城地图上不存在的终点后开始追踪异常路由，花费数年建立了独立于统合部主干网的备用通讯链路网络。主线结束后将锈网从十三条线扩展到超过三十条线。

- **核心动机**：维护信息自由流通；构建不依赖统合部的独立通信基础设施；用数据的力量推动改变。
