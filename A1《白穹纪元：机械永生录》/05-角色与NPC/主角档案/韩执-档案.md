# 韩执 角色档案

- **身份/职务**：韩序之兄，伊甸核心数据链路维护工程师。四十七岁，工龄十九年四个月零七天。前传主角。在伊甸核心维护站工作期间，从统合部数据总线上直接截取了清理行动的原始监控记录（三段核心影像），加密存入黄铜数据芯片，通过内部物流系统寄给弟弟韩序。后因学徒明出卖被审查官维拉逮捕，送入伊甸核心接受意识抽离手术。

- **出现章节**：主线第02章（被提及）、第10章、第19章（录音）、第21章、第22章（影像）、第31章；前传第01-12章全部

- **核心动机**：发现真相后，在理解清理行动背后资源逻辑的同时，无法活在一个建立于"你该为别人让出位置"之上的世界中而不让别人知道真相。

- **内心秘密/创伤**：他知道清理行动的真相并理解背后的资源逻辑——甚至认为自己在决策者位置上也可能会做出同样的选择。但理解不等于认同。他在基底神经节最深层植入了一段隐藏程序，每天下午五点二十三分发送一组脉冲信号到右手无名指（在被发现前为自己留的后路）。被送入手术室前最后回想的画面是和韩序小时候在白穹城广场上放纸飞机。

- **所信的谎言（如有）**：起初相信进入伊甸核心维护岗位是普通的工程工作，后在工作中发现异常并逐步拼凑出真相。

- **角色弧线（故事中的变化）**：从伊甸核心工程师→发现异常的人→用一年时间确认→获取证据→寄出芯片→被捕送进伊甸。他不是天生的反叛者，他只是一个在十九年日常工作中"会多看一眼"的普通人。

- **与其他角色的关系**：
  - 韩序：弟弟，将加密芯片通过内部物流系统寄给他。留下的录音说"不要相信我说的任何一个字。但我希望你理解，他们做这些事，不是因为他们坏，而是因为他们还没有找到更好的办法。"
  - 明：学徒，十九岁D级技术员，被维拉安排为内应，最终出卖了韩执。
  - 审查官维拉：被维拉侦破和逮捕。
  - 韩序的妻子：通过她哥留下的线索间接关联。
