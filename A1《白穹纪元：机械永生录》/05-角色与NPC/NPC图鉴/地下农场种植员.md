# 地下农场种植员 角色档案

- **身份/职务**：铁锈带废弃地铁站深处经营地下农场的种植者。原白穹城积分公民，因不知名原因被流放后，选择了一个在地下的、不需要和任何人打交道的位置，独自经营一套从旧世界农业手册中复原的水培系统。

- **出现章节**：主线第16章相关背景

- **核心动机**：自给自足——在被系统判定为"没有价值的人"之后，用旧世界的知识和废品站的材料自己制造生存资源。

- **背景设定**：铁锈带中少数不依赖"回收"和"交换"而靠"生产"生存的人。他种出的新鲜蔬菜在黑市上可以卖到很高价格——因为铁锈带几乎没有任何天然耕地，新鲜植物意味着奢侈本身。

- **行为特征**：话极少——长年独居已让说话变成"非必要行为"。双手几乎不停歇，能通过叶片边缘轻微卷曲判断营养液氮磷钾比例，通过根系颜色变化判断水温。

- **视觉信息**：详见美术视觉/角色美术/地下农场种植员.txt——深灰色旧连体工装，六个口袋；头顶旧矿灯（灯罩一道裂纹用透明胶带缠着）；双手永远带着淡绿色营养液残留和深色泥土。地下空间中多层水培架用废弃地铁座椅金属框架和排水管拼接。
