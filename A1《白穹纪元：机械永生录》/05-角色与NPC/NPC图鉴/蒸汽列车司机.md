# 蒸汽列车司机 角色档案

- **身份/职务**：白穹城→铁锈带的蒸汽列车驾驶员。驾驶SL-07专用配给列车的资深司机，同一条线路跑了十几年，对每一段轨道的坡度、每一个弯道的离心力、每一处铁轨接缝位置都了如指掌。

- **出现章节**：主线第01章、第04章、第12章、第14章等多处场景

- **核心动机**：没有个人动机——他的工作是开车，不是了解开了谁去了哪里。在白穹城铁轨上不会和人产生任何超出"发车"和"到站"两个指令以外的互动。

- **背景设定**：白穹城→铁锈带的物理通道的执行者。他驾驶的SL-07列车是小说中最重要的空间切换标志。他是这条通道上最沉默的见证者，见过成百上千个被押上车的流放者，但从不问也不看。

- **行为特征**：列车运行中极少说话——驾驶室噪音太大，任何超过三个词的对话都需要靠吼。时间由调度表和蒸汽压力共同决定：压力够了就发车，到站了就拉闸。

- **视觉信息**：详见美术视觉/角色美术/蒸汽列车司机.txt——厚实铁锈色工装，面料泛着洗不掉的暗黑色。手背和指缝嵌着常年渗入皮肤的煤灰。护目镜挂在胸前或推在额头上。操纵台由一排铜质阀门和钢制拉杆构成。
