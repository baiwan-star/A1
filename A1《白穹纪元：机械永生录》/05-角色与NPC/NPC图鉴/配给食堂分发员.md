# 配给食堂分发员 角色档案

- **身份/职务**：白穹城积分筛选区标准配给食堂窗口分发员。编号不明，姓名不详。白穹城底层服务岗位，承担最机械化的配给环节。

- **出现章节**：主线第04章

- **核心动机**：无个人动机——其存在被简化为"将标准份量食物从A点转移到B点"这一动作本身。

- **背景设定**：白穹城高度分工与社会原子化的缩影。在统合部体系中，一个人的完整人格在岗位描述之外的多余部分是不被需要的——不需要表达、不需要情感、不需要个性。

- **行为特征**：不说话，不抬头，视线始终落在餐盘面上。动作经上千次重复已自动化。轮班结束时摘下手套放入回收桶，套上新手套继续下一个班次——像不需要关机重启即可持续运行的设备。

- **视觉信息**：详见美术视觉/角色美术/配给食堂分发员.txt——白色工作服，无姓名牌，仅统合部后勤通用齿轮徽章。白手套指尖泛灰黑色。眼神空洞不聚焦于排队者。
