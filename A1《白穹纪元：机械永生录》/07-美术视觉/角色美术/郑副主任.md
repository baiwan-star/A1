# 郑副主任

- 身份：白穹城数据审核中心副主任，洛安的直属上级。在系统内部注意到了洛安对韩序案卷的异常查询，选择用自己的权限在系统日志中覆盖标记保护洛安，而不是将其上报。

- 出现章节：主线第09章

- 外貌特征：中等年纪，穿着数据审核中心中层的深灰色制服——比普通审核员的米灰色略深，面料质感略好。皮鞋，步伐稳定。说话时目光不落在交谈对象身上，而是落在桌面上的表单上——仿佛表单的签字顺序才是他真正关注的事。语气中既没有责备也没有同情，只有在陈述一个他已经处理完毕的事实时的平静。但在说出关键警告时语气中有一丝极细微的颤抖——不是恐惧，而是一种小心翼翼的提醒，像是希望对方能听懂背后的含义。

- 服装道具：数据审核中心中层制式深灰色制服，皮鞋。办公室里有一张标准办公桌。他的工位在办公室中，有独立的门将办公区与大厅隔开。

- 行为特征：走到洛安工位前时没有坐下的意思。说话时没有看洛安的眼睛。声音平稳，音量控制在只有附近几个工位能勉强听到的程度。主动在系统审计日志中的异常访问记录上做了覆盖标记，标注为"常规业务查询，无需进一步处理"，并在二级复核栏中签了字。他没有将洛安的异常访问记录转给思想安全局——那本应是标准流程。他选择替洛安掩盖，这个选择本身传达的信息超过任何语言：郑副主任也不认为韩序的案件按照常规标准是清白无误的。他说完关键信息后站了两三秒，然后转身沿着工位之间的主通道往回走，皮鞋声在空旷的大厅中渐行渐远，在经过几排空工位后拐弯，被关上的办公室门切断。

- 关键台词："你还有九十一天飞升。你已经为这件事做了三十七年的准备。到这个程度就可以了。到此为止。"
  "有些数据不是你这个级别能看的。"（语气中有一丝极细微的颤抖）
  "我已经在那条访问记录上做了一个覆盖标记，标注为'常规业务查询，无需进一步处理'。那条标记已经生效。"

- 与世界观关联：系统内部的"好中层管理者"。他理解系统的规则，知道如何在规则内保护下属。他没有公开质疑韩序案件——公开质疑等于思想污染。但通过保护一条与案件相关的异常查询记录来间接表达立场，是在现有制度框架内能做的、不触发任何系统预警的最高程度的抗议。他的存在本身就说明系统内部有人注意到了异常走向——尽管那些人选择用沉默的方式表达。
