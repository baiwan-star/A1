# 黄铜数据芯片

- **类别**：存储介质/加密数据载体
- **出现章节**：第10章·数据盘、第12章·最后91天、前传第06章·数据盘、第19章·铁砧的过去、第21章·韩执的记忆、第22章·伊甸
- **持有者**：韩执（制作者）→ 韩序 → 洛安 → 灰羽（破译）→ 洛安（植入F-17端口）
- **物理描述**：
  标准制式的黄铜数据芯片——在铁锈带走私网络中为通用规格，外壳磨损但内部存储单元完好。圆形金属外壳，边缘有轻微倒角处理。由一枚废旧继电器外壳改装而成的密封小管作为原始保护壳。侧面的标识带上写有一串编码。总体积很小，可轻松放入衣物内袋中。

  **内容**：韩执用神经接驳者的维护权限直接从伊甸核心手术室数据总线拷贝的原始监控记录——包括三组核心影像文件和若干段神经接口录制的个人语音笔记。影像一：意识抽离手术全过程（精密机械臂从活体大脑中逐一摘除神经记忆体）；影像二：空壳收容区日常（数百个被摘除意识的人形躯体排列在金属支架上）；影像三：无害化处理流程（失去利用价值的空壳被送入终端焚烧炉）。影像边缘叠加的实时数据总线信息意味着这些画面是韩执直接从统合部内部数据总线上截取的原始信号，不是经过二次处理的翻拍版本，真实性无可辩驳。

- **关键功能**：
  芯片被加密封装，加密级别为神经接驳者级别的个人密钥——整个铁锈带能解开的人屈指可数。灰羽花了三天研究密钥结构。芯片被洛安植入数据审核中心中央机房的F-17端口，设72小时后自动触发——覆盖白穹城约43%公共CRT终端持续46秒，公开播放在伊甸核心的内部画面。这是整个故事的信息点火装置——真相以原始数据的形式从统合部内部数据总线流出，经铁锈带的技术孤岛破译，再通过统合部自己的公共信息通道在系统的城市中播放。一个完美的信息回路闭环。
