# 中央数据中枢机房

- **位置**：白穹城中心地下，数据审核中心地下一层以下，统合部中央数据中心地下二层
- **出现章节**：第01章·不眠之夜、第30章·72小时、前传第01章·数据之眼、前传第02章·不该看的信号
- **空间布局**：
  无尽的CRT服务器阵列排列在昏暗的机房中，机柜之间的通道仅容一人通过。机房东墙的F-17端口所在面板位于中部机柜段。地下二层存放着统合部早期部署的数据记录装置——一排排两人高的黄铜矩阵架排列在幽暗的走廊两侧，每一台装置表面嵌着密密麻麻的真空管和接线端子。老旧的铁灰色CRT终端显示器以相同间距排列，机柜内指示灯以红绿相间的色温规律排列。

- **视觉构成**：
  **照明**：主要光源来自成排CRT服务器阵列的指示灯——红绿两色，在黑暗中以规律间隔排列。部分旧设备区域依靠黄铜架上的暗淡指示灯和应急灯照明。地下二层走廊两侧的壁灯灯罩布满积尘，光线微弱，只能照亮脚下两步距离。
  **管道系统**：透明的冷却液管道在服务器之间蜿蜒，折射着指示灯的红光，在机房地面上投下波光粼粼的暗红色光影。液压管线沿天花板中轴线走，每隔1.2米一个黄铜固定卡扣，垫0.3毫米的橡胶垫片。
  **声音**：服务器散热风扇的持续白噪音，昼夜不变，不受人类在场状态影响。
  **温度**：机房低于走廊温度，湿度控制精确。地下二层比上层低约5℃，呼吸形成淡淡白色雾气。空气中弥漫电子管工作时的微热和臭氧混合气味——暴风雨前的电离感。
  **氛围**：黑暗中的算法心脏。数千万人的生命维持数据、积分记录、物资调配记录在此以光速流动。

- **功能用途**：
  白穹城数据系统的物理中枢，承载伊甸核心的数据链路、全城CRT终端信号分配、物资调配记录存储等核心功能。神经接驳者的维护工作区——韩执维护了19年。

- **关键事件**：
  韩执在此发现二十年前清理前后的物资消耗数据（消耗下降43%，意识到清理的真实动机是资源分配而非防疫）。洛安在此将数据芯片植入F-17端口，设72小时自动触发。白袍与洛安在此进行关键信息传递（铁锈带坐标和统合部真实资源模型数据）。
