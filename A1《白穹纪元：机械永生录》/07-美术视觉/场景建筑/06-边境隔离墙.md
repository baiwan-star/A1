# 边境隔离墙

- **位置**：白穹城与铁锈带之间的物理分界线，7号检查站附近
- **出现章节**：第14章·黑色通道、第29章·穿越、第15章·铁锈的天空
- **空间布局**：
  高约120米的钛合金墙体。墙体两侧维护状态完全不同：白穹城一侧为光洁的白色涂料墙面，定期维护；铁锈带一侧为未经处理的混凝土原色，布满风化的龟裂纹和工业沉积物。墙体顶端排布电磁封禁网和自动火力塔光学传感器单元，以均匀间距分布在顶部支撑架上。底部有一处废弃检修入口——盖板因几十年工业粉尘沉积自然伪装成与周围墙面几乎无法区分的形状。

- **视觉构成**：
  同一面墙从两侧看呈现两个世界：白穹城侧光洁白涂料象征秩序与文明；铁锈带侧混凝土原色布满裂缝和污渍——"系统不愿意投资维护的那一面"。墙顶传感器单元在铁锈带侧暴露着未经涂漆的金属原色——灰色钢架上的黑色收发器外壳，带有风沙磨损痕迹。入口盖板表面覆盖暗灰色沉积物，颜色与混凝土墙面几乎无法区分。
  **光效**：清晨从铁锈带望向墙体时，白穹城方向的白光照在墙体顶端形成一道亮线。配给列车在围墙入口短暂停靠时，墙体外侧监控指示灯以固定顺序从右到左闪烁。

- **功能用途**：
  将"可管理的文明"（白穹城）与"不可管理的遗弃"（铁锈带）在物理空间上绝对隔离。阻止铁锈带居民返回白穹城，同时对白穹城公民形成不可逾越的心理屏障。

- **关键事件**：
  洛安通过黑箱通道走出白穹城，SL-07列车在此将他释放到铁锈带侧。后来他借助配给列车47天的信号间歇窗口，通过废弃检修口盖板反向穿越回到白穹城内部完成芯片植入。灰羽通过监控信号周期分析发现了这段二十分钟的静默窗口。
