# 白穹纪元·机械永生录 · 制造/生产/采集系统 v1.0

## 一、设计核心思想

**制造采集在本世界不是"生活职业"，而是铁锈带最真实的生存方式。**

白穹城公民不需要采集或制造——他们拥有统合部的统一配给，一切生活物资由机械仆从和生产流水线保障。但在铁锈带，一颗螺丝、一段铜管、一枚完好的电路元件，都意味着你能多撑一天。

制造采集系统的设计原则：**不做常规MMO里的"资源→配方→成品"的枯燥循环，而是将这个系统打造成世界观叙事的一部分。** 你在铁锈带采集的每一块废料、制造的每一件装备、种植的每一株蔬菜，背后都有一个关于"人如何在废土中活下去"的故事。

## 二、采集系统

### 2.1 区域分布与资源类型

采集行为**仅限铁锈带**。白穹城区域内没有任何采集玩法——统合部的配给体系使白穹城公民不需要捡垃圾，而在白穹城内捡垃圾的行为会被思想安全局标记为"异常行为"。

| 区域名称 | 资源类型 | 危险等级 | 采集效率 |
|---------|---------|---------|---------|
| 铁锈带边缘 | 基础金属零件、废铁片、旧螺栓 | 低 | 慢（资源分散） |
| 废弃工业区 | 铜导线、电路板碎片、液压管件 | 中 | 中 |
| 废弃工厂深层 | 完整电路模块、稀有合金、燃料残渣 | 高 | 快（资源富集） |
| 垃圾山 | 混合废料（随机产出，从上到下密度递增） | 低-中 | 随机（下限低上限高） |
| 伊甸隔离墙外围 | "白穹城废弃物"——可产出完整度极高的工业零件 | 极高 | 极快（但生存几率低） |

### 2.2 采集方式

**手工拾取（基础）**
- 玩家在铁锈带废料堆、废弃设施中按"交互键"进行拾取
- 消耗少量体力值（非耐力条，为独立资源，可通过休息和食物恢复）
- 单次采集产出 1-3 个基础材料
- 基础材料可堆叠，占用背包少量空间

**工具辅助采集（进阶）**
- 废铁机械师制作的"拆解工具"（扳手、电动磨具、液压钳）可提升采集速度和单次产出量
- 不同工具对不同材料类型有加成（如液压钳对金属管件有200%效率加成，但对电子元件无效）
- 工具本身有耐久度，可在工坊维修

**载具辅助运输（高阶）**
- 拥有载具的玩家可采集后快速返回据点卸载材料，大幅减少往返时间
- 载具背箱提供额外临时仓储空间（约普通背包的 3 倍）
- 载具油耗（蒸汽机车头的煤炭消耗/内燃机车的燃料消耗）是运输采集的核心成本

### 2.3 采集产物按等级分类

| 等级 | 代表产物 | 用途 |
|-----|---------|------|
| 基础 | 废铁片、旧螺栓、磨损齿轮、断电线 | 基础修理、低级制造 |
| 中级 | 完整电路板、黄铜接头、液压管段 | 装备制造、义体改造 |
| 高级 | 稀有合金锭、加密芯片残件、高纯度燃料 | 特殊装备、高级义体 |
| 传说 | 旧世界设备核心模块、统合部制式零件 | 限量制造、剧情道具 |

**采集物有随机品质波动**：采集同一堆废料，可能得到"锈蚀的螺栓"（基础）或"完好的钛合金螺栓"（中级）——这是铁锈带最核心的乐趣体验之一：你永远不知道下一堆垃圾里能翻出什么。

## 三、制造系统

### 3.1 制造核心

| 制造用途 | 说明 |
|---------|------|
| 修理现有装备 | 消耗基础材料修复装备耐久度 |
| 制作新装备 | 使用图纸+材料制作武器/防具/义体模块 |
| 消耗品制作 | 弹药/燃料包/急救包(铁锈带版)/过滤水/简易防毒面具 |
| 载具改装 | 更换载具部件——装甲板/引擎/货箱/蒸汽压力阀 |

### 3.2 工坊体系

制造不是在个人背包中完成的——玩家需要使用地图上的**工坊设施**：

| 工坊类型 | 位置 | 能力上限 | 使用条件 |
|---------|------|---------|---------|
| 废铁机械师工坊 | 铁锈带各据点 | 高级制造 | 支付零件使用费或与对应机械师交好 |
| 个人工坊（家园） | 中立区（解锁家园后） | 中级制造 | 需要自行添置设备模块 |
| 帮派共享工坊 | 帮派领地 | 高级制造 | 帮派成员免费使用 |
| 铁砧工坊（特殊） | 铁锈带·铁砧据点 | 传说级制造 | 需完成铁砧个人任务链解锁 |

### 3.3 制造配方

- 基础配方由废铁机械师NPC教授（完成新手引导后免费获得）
- 高级配方以图纸形式分布在：黑市商人出售、副本宝箱掉落、赏金任务奖励、帮派领地战奖励
- 配方不是一次性消耗品——学会后永久保留
- 部分传说配方为"盲制"——你只知道材料清单和操作步骤，但不告诉你成品具体是什么，只有制作完成后才看到结果。这是废铁机械师的浪漫：每个传说配方都是一场赌博。

### 3.4 制造品质机制

制造结果浮动在三个品质之间：

| 品质 | 概率（基础条件） | 属性修正 |
|-----|----------------|---------|
| 标准 | 70% | 100%基础属性 |
| 精良 | 20% | 110%-120%基础属性 |
| 完美 | 10% | 130%-150%基础属性 + 额外槽位/特效 |

影响因素：工坊等级、玩家在该类制造上的熟练度（逐件提升）、材料品质（传说材料产出精良/完美概率翻倍）。

## 四、生产系统（中立区限定）

生产系统与采集/制造独立运行，限定在中立区范围内。

### 4.1 水培农业
- 在中立区家园地块中开辟小型水培种植区
- 可种植：铁锈带适生蔬菜、观赏性机械苔藓、药用植物
- 产出用于：烹饪（制作恢复类食物）、交易（稀有蔬菜在黑市可卖高价）、帮贡（上交给帮派换取信义值）

### 4.2 过滤水生产
- 中立区公共过滤塔产出干净的饮用水
- 玩家可参与过滤塔维护（小游戏形式：更换滤芯/清理管道/修复蒸汽泵）
- 产出分配：维护者优先获取 30%，剩余投入中立区公共仓库定向分配
- 过滤水是铁锈带最硬的硬通货之一——可在任何据点与NPC交易，也可以作为帮派领地战的战略物资

### 4.3 公共设施维护
- 中立区的公共设施（公告板、路灯、信号中继站、集水塔）由玩家集体维护
- 每次维护消耗基础零件，获得"中立区贡献度"
- 贡献度用于：解锁高级公共设施使用权限、在中立区购买地块、获得中立区居民的身份认可

## 五、系统之间的联动

```
采集 ──→ 制造 ──→ 装备/义体/消耗品
   │                    │
   └──→ 交易（拍卖行/黑市） ←──┘
   
生产 ──→ 食物/水/药品 ──→ 中立区发展
   │
   └──→ 帮派/据点贡品 ──→ 信义值/好感度
```

**采集→制造→装备**构成核心循环：废土中捡垃圾→拼凑成武器和义体→用它们去更危险的区域捡更好的垃圾。

**采集→交易→货币**构成经济循环：不想自己制造？把原材料卖给其他玩家或NPC，换取货币再买现成的。

**生产→中立区贡献**构成社区循环：这不是一个人的游戏——中立区的每一升水、每一根菜，都是某个玩家亲手种出来的。

## 六、红线与限制

- **制造不产出顶级装备**——传说级制造的上限等于中高级副本的装备水平，真正的顶级装备必须从副本中获取。制造的优势在于你**可以选择要做什么种类的装备**，而不是属性上限更高
- **采集没有"肝度门槛"**——低等级区域也能采集到高级材料（概率低但存在），不逼玩家必须去最高难度区域才能体验采集的乐趣
- **白穹城线玩家不参与制造采集**——作为世界观设定的延伸，白穹城出生玩家无法采集（没有对应交互动作）也无法制造（没有工坊使用权限），但可以通过交易系统购买到铁锈带玩家制造的物品
- **制造配方永不绑定**——你学到的配方就是你的，删号重来也保留
