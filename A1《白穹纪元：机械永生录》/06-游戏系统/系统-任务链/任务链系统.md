# 白穹纪元·机械永生录 · 任务链系统 v1.0

## 一、设计核心思想

**任务链不是"任务清单"，而是你在这个世界中留下的行动轨迹。**

主线任务严格沿小说章节推进，但游戏的任务系统不是小说的流水账改编——它的目标是让玩家"活进"洛安的故事中，而不是仅仅"看过"洛安的故事。每一个任务节点都是一个可交互的叙事切片。

白穹城线的任务以数据审核、思想确认、社区检举等"日常仪式"为填充；铁锈带线的任务则是废土生存的实战考验——追逐、猎杀、逃脱、合作、背叛。两条线的任务风格截然不同，体现两个世界的底层逻辑差异。

## 二、任务类型

### 2.1 主线任务（白穹城线 + 铁锈带线）

**对应结构：** 主线 13 章，每章含 3-5 个任务节点，共约 50-65 个主线任务

**设计原则：**
- 任务严格按照小说剧情节点的顺序排列，同时通过白穹城线与铁锈带线的事件分流，让玩家在双重视角下理解剧情全景
- 重要剧情节点以演出（CRT终端影像/脑网信息流/环境叙事）形式呈现，而非纯文本对话
- 主线任务之间穿插"自由活动窗口"（可接取支线/探索/采集/战斗），避免纯线性推进的疲劳感
- 前传/后传内容整合至 DLC 任务中，不影响主线的节奏感

**任务记录：** 主线任务的进度以「章节+当前步骤」的形式记录在CRT终端任务日志中，附有一段由系统自动生成的"案件摘要"（统合部档案风格：编号、时间、描述、状态）。当主线推进到重大转折点时，摘要栏会多出一行大字号的红色标题，以统合部"重大事件记录"的风格标注该节点的名称。

### 2.2 支线任务

支线任务分散在各章的自由活动窗口中，按来源分为以下几类：

**① 白穹城 · 统合部指派任务**
- 来源：数据审核中心的系统下派任务
- 内容：数据比对、异常报告填写、终端维护、物资清单核对
- 风格：中性叙述、无叙事起伏、按标准流程完成即可
- 奖励：积分（少量）、思想评分小幅提升

**② 白穹城 · 思想安全局协助任务**
- 来源：思想安全局官方向"可信公民"（高思想评分者）下派的"市民协助请求"
- 内容：协助核实举报信息、查看邻里异常行为报告、跟进被流放者的物资领用清单
- 风格：语气官方但措辞微妙——任务描述中逐渐出现一些"超出标准模板范围"的细节描述
- 奖励：积分（中量）、思想评分显著提升
- 这些任务的微妙之处在于：完成越多，越接近某些不该被看见的信息

**③ 铁锈带 · 废铁机械师委托**
- 来源：铁砧及其他废铁机械师发布
- 内容：回收特定零件/为机械师跑腿/清理工坊附近的硅基生物巢穴/护送材料运输
- 风格：直来直去的废土需求，不绕弯子，不伪装
- 奖励：铁锈带货币、机械零件、修理服务、制造配方

**④ 铁锈带 · 帮派悬赏**
- 来源：各帮派头目
- 内容：敌对帮派成员的定点清除/资源抢夺计划的执行/地下运输路线的开辟/帮派比武的参赛
- 风格：严肃、粗粝、带威胁——"不干活就没有物资分"
- 奖励：帮派信义值、武器/义体零件、帮派专属商品购买权

**⑤ 铁锈带 · 锈网行者情报任务**
- 来源：灰羽及锈网行者网络
- 内容：携带加密数据盘穿越敌对区域/破解废弃终端残留数据/设置信号中继站/监听统合部通讯频段
- 风格：紧张、隐秘——"不要告诉任何人你做了这件事"是标准的任务开场白
- 奖励：铁锈带货币、稀有情报碎片（解锁世界叙事文本）、加密通讯设备升级

**⑥ 铁锈带 · 赏金任务**
- 来源：各据点黑市商人
- 内容：城外硅基生物猎杀/稀有矿物采集/觉醒变异体清剿/危险区域的物资回收
- 风格：任务描述极简，仅包含目标坐标+悬赏金额+已接取人数
- 奖励：铁锈带货币、特殊材料
- 赏金任务不记名——任何人都可以接，任何人都可以在你完成任务后抢走你的战利品（PVP 模式参见PVP系统）

**⑦ 中立区 · 社区建设任务**
- 来源：中立区公共公告板
- 内容：过滤塔维护/配电线路清理/公共居住单元加固/物资储备分拣
- 风格：质朴、平实——"如果你有时间和力气，来这里搭把手"
- 奖励：中立区贡献度、基础物资、中立区居民信任度（影响后续剧情分支）

**⑧ 中立区 · 居民委托**
- 来源：中立区各住户
- 内容：寻找丢失物品/代送口信/修理故障家用机械/陪伴前往较远的采集点
- 风格：私人化、充满细节（每个委托人的故事都不相同）
- 奖励：居民好感度（可能解锁额外对话和隐藏线索）

### 2.3 DLC任务

- DLC1（前传）：体验韩执在伊甸核心中发现真相的全过程——12个任务节点，以一个黄铜数据芯片的制造、加密、寄出为主线
- DLC2（后传 Part 1）：两年后的五方格局——维拉追猎行动、灰羽被捕、洛安的决定
- DLC3（后传 Part 2）：教育法案4:4决议——洛安与维拉的交易、裂缝之后的沉默

DLC任务的推出机制：主线打通第13章后自动解锁DLC1；DLC1完成后解锁DLC2；DLC2完成后解锁DLC3。按时间线顺序体验，不可打乱。

## 三、任务触发方式

| 触发方式 | 说明 | 示例 |
|---------|------|------|
| 剧情事件触发 | 主线自然推进 | 阅读韩序流放通告 → 触发"追查IN44" |
| NPC对话触发 | 与特定NPC交流 | 铁砧递过来一把螺丝刀："帮我把西边那台水泵拆了，零件归你。" |
| 区域探索触发 | 进入特定地点 | 首次进入废弃工厂→发现数据盘 → 触发"数据盘解码" |
| 场景物品交互 | 点击/检查特定物品 | 检查韩序公寓的书架 → 发现被打乱的书脊文字密码 |
| 时间条件触发 | 等待特定时间 | 铁锈带黑市在每天黄昏开张→自动触发"黑市接头"任务 |
| 成就条件触发 | 达成指定进度 | 采集100份材料后→废铁机械师主动发布"你是个干活的料"任务 |
| 声望条件触发 | 某帮派/势力达到一定好感度 | 白袍好感度≥30→触发白袍个人支线 |
| 跨区触发 | 白穹城线做某个决定→铁锈带线解锁新选择 | 白穹城中拒绝举报同事→铁锈带线解锁"未举报者"的隐藏对话分支 |

## 四、任务日志界面

### 4.1 CRT终端界面设计

任务日志以CRT终端低分辨率显示风格呈现：
- 背景色：暗绿色
- 字体：像素化CRT字符
- 分隔线：ASCII字符画 ——— ——— ———
- 高亮：反白背景（白字黑底）

### 4.2 日志结构

```
┌─ 白穹纪元 · 任务日志 ────────────────────┐
│                                             │
│  当前任务链（高亮）：                       │
│  ▸ 主线·第4章：自愿跌落                   │
│     步骤 2/4：查看配给列车时刻表           │
│                                             │
│  ◻ 支线任务                                │
│    - 帮铁砧找一根8mm液压管                 │
│    - 向灰羽提交一份锈网节点报告             │
│                                             │
│  ◇ 可接取任务（当前区域范围内）           │
│    - [赏金] 猎杀：城外硅基生物 ×5          │
│    - [委托] 黑市商人：运送一箱医疗物资      │
│                                             │
│  [状态] 正在进行 | [日志] [收藏]           │
└─────────────────────────────────────────────┘
```

### 4.3 任务追踪

- 玩家可在终端界面上"置顶"最多 3 个任务——置顶任务在玩家视野右上角显示简要信息（任务名+当前步骤）
- **无小地图任务指引箭头**——你需要根据任务描述中的"区域描述+标志物"自行定位目标位置（"废弃工厂的第三层，一个原用于蒸汽排放的管道平台"比一条直线箭头更有世界沉浸感）
- 首次进入新区域会有CRT终端显示"区域情报摘要"——该摘要可以帮助定位任务目标，但不提供精确坐标

## 五、分支选择与影响机制

### 5.1 影响维度

玩家在任务中的选择影响以下四个维度：

| 维度 | 受什么影响 | 影响什么 |
|-----|-----------|---------|
| 思想评分 | 白穹城线中选择"系统期望的选项"扣减、"非标选项"评估 | 主线推进方向、白穹城NPC态度、部分任务的解锁/封锁 |
| 信义值（铁锈带） | 铁锈带线中的承诺完成度、帮派任务选择 | 黑市交易折扣、帮派领地准入、部分NPC的信任度 |
| 合众度（白穹城） | 举报行为、思想评分表现、积分排行榜位置 | 统合部系统内的高级权限、白穹城特殊区域准入 |
| 势力好感度 | 五方势力的任务选择和阵营偏好 | 剧情事件走向、特殊装备获取、角色关系结局 |

### 5.2 分支示例

**主线第2章 · 思想确认题**
- 选择A：按标准答案填写"伊甸核心是绝对的幸福之地"
- 选择B：填写"也许应该给飞升者更多与外界接触的权利"（非标选项，轻度思想污染）
- 影响：A → 积分+100，主线正常推进；B → 积分-50，触发"思想安全局约谈"支线，解锁后续隐藏选择

**前传DLC · 韩执的决定**
- 选择A：将所有数据加密进芯片，寄给弟弟韩序
- 选择B：选择沉默，维持现状
- 选择C：直接向最高委员会举报
- 影响：A → 触发主线（默认路线）；B → DLC提前结束，获得"沉默者"称号，但不解锁主线关键信息；C → 韩执即刻被捕，DLC在第三章戛然而止，获得"殉道者"称号

## 六、红线与限制

- **所有任务必须在世界观逻辑内自洽**——不出现"踢开统合部大门正面硬刚"这种违背世界情感内核的任务设计
- **主线任务不可跳过**——但可以通过完成特定支线获得"跳过战斗环节"的选项（如支线收集到一份通行证→主线的潜入战斗可以换成潜行通过路线）
- **没有每日/每周强制任务**——所有任务是"可做可不做"的，如果不做，不会导致角色在核心属性上被拉开差距
- **任务数量和密度**——不搞"跑腿100次"的无意义任务，每类支线任务的上限在 5-15 个之间，保证每个任务都有独特的叙事内容
