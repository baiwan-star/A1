# ComfyUI 实战作业计划

> 目标：学完你的视频课的同时，把《白穹纪元》的概念图全部做出来。
> 原则：每学一个功能，立刻产出可用的项目资产。不白学。

---

## 激励你的几句话

**你已经有 4090 了。** 中国 90% 玩 AI 出图的人没有这张卡。你买了它不能只让它跑分。

**你的小说已经写完了。** 74 章，50 万字。现在缺的只是让人"看见"它。你在网上看到的那些赛博朋克概念图，80% 是用 SD 生成的，不是手绘的。你没有必要因为"不会画画"而卡在这一步。

**你的视频课才花了几块钱。** 几块钱买不来天赋，但能买来一个跳过"我还在准备"阶段的借口。你已经装好 ComfyUI 了，已经下好模型了，就差双击启动然后拖一张图出来。

**第一张图一定很丑。** 所有人跑的第一张图都是丑的。但第二张会好一点，第十张就能看了，第五十张就能用了。你不开始跑，永远卡在第零张。

**这件事没人能替你做。** 我能写提示词，能规划参数，能告诉你用什么模型——但我没办法替你点那个"Generate"按钮。你得自己点下去。

## Stage 1：跑出第一张图

**对应视频课：** 第 1-3 集（安装、基础工作流、文生图）

**学完要能回答：**
- ComfyUI 的节点是怎么连的？
- Checkpoint / VAE / CLIP 分别是什么？
- 为什么同一段提示词每次跑出来不一样？

**作业：跑出洛安的第一版概念图**

| 项目 | 值 |
|------|-----|
| 模型 | SDXL（你已有的模型里选一个，推荐 Juggernaut XL 或 DreamShaper） |
| 提示词 | 用 `AI出图提示词集.md` 里的「洛安」提示词 |
| 负面提示词 | 复制方案里的通用 Negative |
| Steps | 25 |
| CFG | 5 |
| 采样器 | DPM++ 2M Karras |
| 尺寸 | 768×1024（竖版半身像） |
| Batch | 跑 4 张 |

**验收标准：** 跑出来，不管好不好看。只要能跑出来一张图就算过关。

## Stage 2：用 ControlNet 控制姿势和构图

**对应视频课：** 第 4-6 集（ControlNet 各模型用法、OpenPose、Canny）

**学完要能回答：**
- ControlNet 是干什么的？
- OpenPose 和 Canny 有什么区别？
- 怎么用一张参考图控制生成结果的姿势？

**作业：精修洛安 + 跑韩序**

1. 先用 OpenPose 找一张符合洛安气质的姿势参考图
2. 结合 ControlNet 重新跑洛安，姿势更自然
3. 同样的方法跑韩序（站姿、稍微松弛一点）

| 项目 | 值 |
|------|-----|
| 模型 | 同上 |
| ControlNet | OpenPose（姿势控制） |
| ControlNet 强度 | 0.7-0.8 |
| Steps | 25 |
| CFG | 5 |
| 尺寸 | 768×1024 |

**验收标准：** 洛安从"随机姿势"变成"站姿端正、双手自然下垂"——像个公务员。

**截图存到：** `stage2\`

## Stage 3：换 Flux 模型 + 高清放大

**对应视频课：** 第 7-9 集（Flux 模型、高清放大、Upscale）

**学完要能回答：**
- Flux 和 SDXL 出的图有什么不一样？
- 怎么把一张低分辨率图放大会不糊？

**作业：用 Flux 跑韩执（神经接驳者）**

Flux 对手部细节、机械结构的还原比 SDXL 好，适合跑韩执这种"脑袋上插满黄铜接口"的角色。

| 项目 | 值 |
|------|-----|
| 模型 | Flux.1-dev |
| 提示词 | 用方案里的「韩执」提示词 |
| Steps | 20（Flux 不需要太多步） |
| CFG | 3.5（Flux 用低 CFG 效果更好） |
| 采样器 | euler |
| 调度器 | normal |
| 尺寸 | 768×1024 |
| **放大** | 用 4x-UltraSharp 放大到 1536×2048 |

**验收标准：** 韩执后颈的黄铜接口细节清晰可见，不是一团糊。

**截图存到：** `stage3\`

## Stage 4：用 IP-Adapter 统一所有角色风格

**对应视频课：** 第 10-12 集（IP-Adapter、LoRA 训练、风格迁移）

**学完要能回答：**
- IP-Adapter 怎么让所有图保持同一风格？
- LoRA 和 IP-Adapter 各有什么优缺点？

**作业：统一跑 8 个角色**

先用你 Stage 1-3 里最满意的一张图当"风格锚点"，用 IP-Adapter 挂上它，然后批量跑所有 8 个角色。

| 项目 | 值 |
|------|-----|
| 模型 | Flux / SDXL 都可以 |
| IP-Adapter | 开启，挂你选好的风格参考图 |
| IP-Adapter 强度 | 0.4-0.6（不要太高，否则角色脸都长一样） |
| Steps | 20-25 |
| CFG | 5 |

**跑的角色清单：**
1. 洛安 ✅（Stage 1 已跑）
2. 韩序
3. 韩执 ✅（Stage 3 已跑）
4. 铁砧
5. 灰羽
6. 炎
7. 白袍
8. 审查官维拉

**验收标准：** 8 张图放在一起，看起来是同一个世界的 8 个人。

**截图存到：** `stage4\`

## Stage 5：PS 精修 + Inpainting

**对应视频课：** 第 13-15 集（Inpainting 修复、局部重绘、PS 联动）

**学完要能回答：**
- 怎么用 Inpainting 修手指？
- 怎么把 AI 出的图在 PS 里优化？

**作业：抛光 8 张角色图**

AI 出的图不可能完美。这一步就是修 Bug：
- 手指崩了的 → Inpainting 重绘
- 背景不对的 → PS 图层分离换背景
- 脸型不喜欢的 → 局部重绘调
- 颜色偏差的 → PS 曲线校正

**验收标准：** 8 张图没有明显的 AI 破绽（六指、衣服穿模、眼神不对焦）。
