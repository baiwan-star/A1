# 白穹纪元：机械永生录 · 竞品与市场分析

---

## 一、市场背景：赛博朋克品类的机会窗口

### 1.1 品类热度

赛博朋克题材自《赛博朋克2077》（2020）大规模出圈后，已成为全球游戏市场中最受关注的科幻子品类之一。Steam标签数据显示：
- "赛博朋克"标签游戏总数：约 1,200+ 款（2026年数据）
- 年均增长率：约 18%（2020-2025）
- 中文赛博朋克游戏搜索量：年均增长 35%（百度指数 / 微信指数）

但品类存在明显的审美疲劳风险——大量新作品沿袭"霓虹+义体+黑客"的夜之城范式，同质化严重。

### 1.2 市场空白

具有独特视觉语言（非夜之城范式）+ 深度叙事（非枪械刷任务）的赛博朋克作品，市场上存在明确的供给缺口。特别是在中文游戏市场，"硬核叙事型赛博朋克"几乎空白。

## 二、直接竞品分析

### 2.1 《赛博朋克2077》（CD Projekt Red，2020 / 2023 2.0大更新）

| 维度 | 分析 |
|------|------|
| 美学 | 霓虹灯+纳米义体+超梦技术 |
| 叙事 | 中度（主线好，支线碎片化） |
| 战斗 | 重度（FPS+顶级RPG化） |
| 世界观 | 企业巨头割据 · 街头文化 · 个人英雄主义 |
| 核心体验 | "成为城市传奇"——超级英雄幻想 |
| 定价 | ¥298（标准版）/ ¥149（历史低价） |
| 销量 | 约 3000 万份（截至2025） |

**与白穹纪元的差异：** 《2077》是"你在这个世界里可以成为任何你想成为的人"（爽感导向），《白穹纪元》是"你在这个世界里什么都改变不了，但你仍然可以选择知道真相"（无力感导向）。完全不同的情感体验。

### 2.2 《暗影火炬城》（钛核网络，2021）

| 维度 | 分析 |
|------|------|
| 美学 | 柴油朋克+动物角色 |
| 叙事 | 轻度（背景故事好但叙事占比低） |
| 战斗 | 重度（类银河恶魔城，近战连招） |
| 世界观 | 动物抵抗军反抗机械统治 |
| 核心体验 | 爽快打斗，轻量剧情 |
| 定价 | ¥168（标准版） |
| 销量 | 约 50 万份 |

**与白穹纪元的差异：** 不同品类（银河恶魔城 vs 叙事RPG），不可直接比较。但同为中文开发者的国产机械朋克作品，证明了中文市场对"非传统赛博朋克美学"的接受度。

### 2.3 《极乐迪斯科》（ZA/UM，2019）

| 维度 | 分析 |
|------|------|
| 美学 | 写实油画风，末世城市 |
| 叙事 | 核心——纯对话驱动，无战斗 |
| 战斗 | 无 |
| 世界观 | 政治哲学思辨，个人身份追寻 |
| 核心体验 | "你是什么样的人"——自我认知的辩证 |
| 定价 | ¥116（标准版） |
| 销量 | 约 500 万份 |

**与白穹纪元的差异：** 纯叙事游戏 vs 有战斗的叙事RPG。受众重叠度高（叙事爱好者），可以作为目标用户的"理想对标品"。

### 2.4 《虚幻勇士：编码重启》（Microids，2022 / 改编）

| 维度 | 分析 |
|------|------|
| 美学 | 卡通渲染科技风 |
| 叙事 | 中等（改编动画IP） |
| 战斗 | 轻量（潜行+黑客） |
| 核心体验 | 怀旧+解谜 |

**与白穹纪元的差异：** IP衍生作品，受众有限，非直接竞争关系。

| 游戏 | 开发商 | 发售年 | Steam评价 | 定价 | 销量估 | 与白穹纪元的可比点 |

## 四、SWOT 分析

### 优势（Strengths）
- 小说74章（正文约23万字）全线完工——世界观和剧情基础远超同类概念阶段
- 独特的美学定位（真空管电子机械）——市场上几乎无正面竞品
- 核心主题"理解但不认同"具有深刻的思想张力——区别于"爽就完事"的赛博朋克
- 全部文字设计已由一人完成——无团队膨胀成本

### 劣势（Weaknesses）
- 概念视觉资产为0——没有概念图的概念阶段对投资人吸引力有限
- 无可玩原型——证明"这是好玩的游戏"的证据链不完整
- 一人团队——投资人可能担忧执行力和后续开发能力
- 题材偏"硬"——对主流大众有一定的认知门槛

### 机会（Opportunities）
- 中文独立游戏市场正值资本窗口期（2024-2026年大量基金涌入）
- 叙事驱动型游戏的Steam销量持续上升（《极乐迪斯科》《Pentiment》等验证了市场）
- AI绘图工具（Midjourney / SD）大幅降低概念图制作成本
- "反乌托邦"在中文内容市场持续热门

### 威胁（Threats）
- 赛博朋克品类可能有新的大作宣布（消息面风险）
- AI泛滥可能导致"概念图廉价化"——投资人视觉疲劳
- 叙事驱动型游戏需要极高的写作质量来支撑，劣质剧本会直接导致项目死亡
- 市场偏好可能转向轻量/社交型游戏（如《幻兽帕鲁》型产品）

## 五、目标用户画像

### 核心用户（Target User Persona）

**User A — 叙事爱好者 · 30岁 · 游戏开发者/媒体从业者**
- 喜欢《极乐迪斯科》《Disco Elysium》《Return of the Obra Dinn》
- 游戏时长：50-200小时/款
- 购买驱动力：剧本质量、世界深度、独特美学
- 价格敏感度：低（愿为优质内容付费）

**User B — 赛博朋克核心玩家 · 27岁 · 设计师/程序员**
- 喜欢《赛博朋克2077》《杀出重围》《观察者》
- 游戏时长：30-100小时/款
- 购买驱动力：视觉风格、世界观自洽性、玩法深度
- 价格敏感度：中

**User C — 视觉猎奇者 · 25岁 · 学生/艺术从业者**
- 喜欢独特风格的独立游戏（《The Last Night》《Cloudpunk》）
- 游戏时长：10-30小时/款
- 购买驱动力：艺术风格、氛围感、社交分享价值
- 价格敏感度：高（等史低/折扣）

## 六、定位总结

**一句话定位：**
> 中文市场第一款真空管电子机械赛博朋克叙事RPG——一个比《极乐迪斯科》更沉重、比《赛博朋克2077》更独特的反乌托邦世界，以一部约23万字正文、全库约27万字的完整小说为底本。

**目标价位区间：** ¥68-¥98（买断制）
**目标销量区间（第一年）：** 30万-80万份
**对标产品的情感体验定位：** 介于《极乐迪斯科》（思辨）和《Norco》（南方哥特）之间

**竞争壁垒：**
1. **独一无二的美学风格** —— 真空管电子机械，目前无竞品
2. **完整的叙事底本** —— 74章已完工，非"边做边写"
3. **自洽的世界观体系** —— 第四版，经过多轮迭代，逻辑闭环
4. **零代沟的内容优先理念** —— 不逼氪、不数值、不取悦算法推荐
