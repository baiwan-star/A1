# 《白穹纪元》简历/面试话术

建议放在"个人项目"或"独立创作"板块，而非"工作经历"：

```
《白穹纪元：机械永生录》— 独立世界观/游戏项目
2025-2026 · 个人独立完成

1. 独立完成约23万字正文（全库约27万字）的科幻小说三部曲（前传12章+主线50章+后传12章），构建完整真空管电子机械赛博朋克世界观
2. 完成14个游戏子系统的全面设计（战斗/PVP/制造/任务/经济/社交/家园/副本/成就/引导/背包/成长/装备/运营）
3. 编写完整游戏策划案（GDD）及商业化材料（市场分析/商业计划书/路演PPT）
4. 产出115份美术设计文档，涵盖建筑/角色/载具/道具/义体/植被/特效等全品类视觉方向
5. 核心风格：真空管电子机械赛博朋克——齿轮/液压/黄铜/CRT，区别于传统霓虹赛博朋克美学

关键词：世界观构建 · 叙事设计 · 游戏系统设计 · 科幻写作 · 美术方向把控
```

## 面试怎么聊

### Q：这个项目你一个人做的？

"是的，世界观、小说、系统设计、美术文字稿全是我一个人。我是做3D场景的嘛，对视觉和游戏系统的理解本身就是我的日常，所以写美术方向文档和系统设计对我来说不陌生。最难的部分其实是小说——74章，正文约23万字，要保证前后逻辑不崩，花了差不多一年时间写完。"

### Q：为什么做这个？

"两个原因。第一，我做3D场景做了这么久，对市面上的赛博朋克风格审美疲劳了——来来回回就是霓虹灯、纳米义体、企业巨头割据这一套。我想做一个'反夜之城'的东西，从视觉语言上就让人知道这是完全不同的世界。

第二，我想证明自己不只是一个能执行指令的美术。我懂世界观构建、懂系统设计、懂叙事——这个项目就是最好的证明。它不是一个点子，是一个已经落地的、完整的、可以演示的东西。"

### Q：这跟你现在面的岗位有什么关系？

"这个岗位做的是3D场景/游戏开发。我这个项目证明了三件事：
一、懂美术方向把控——115份美术设计文档，从角色到建筑到载具到植被，全品类覆盖，我知道怎么跟美术团队配合。
二、懂游戏产品思维——系统设计不是瞎写的，是考虑了开发成本、玩家体验、商业化路径之后的权衡结果。
三、有独立推进能力——没有人催我、没有deadline、没有老板盯着，我自己规划、自己执行、自己收工。这说明了主动性。

我觉得对于任何一个游戏开发岗位来说，这三点都是加分项。"

### Q：后续打算怎么处理这个项目？

"现在在找技术合伙人，准备做原型。但我不急——游戏行业本身就在这，这个IP先养着。目前它的状态已经是一个'可展示'的完整概念了，不是空想。有机会就推进，没机会就先继续做我的3D场景，这玩意儿跑不了。"
