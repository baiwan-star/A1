# 白穹纪元 · 短剧剧本（3集×≤2分钟）

> 预算：极有限 | 总时长：≤6分钟
> 核心主题：理解但不认同
> 风格：真空管电子机械赛博朋克 | 低预算友好（室内场景为主，零大场面）

---

## 选集逻辑

原小说74章（前传12+主线50+后传12），压缩为3集需舍弃大量铺垫和次要角色。
只保留**三个核心戏剧节点**，各对应一个完整的人物弧线：

```
EP1 韩执发现真相 → 选择泄露 → 被抓（前传核心）
EP2 洛安继承遗志 → 全城广播 → 真相炸裂（主线高潮）
EP3 裂缝之后 → 各方的选择 → 再加一杯（后传收束）
```

---

## EP1 · 信号
**时长：** 约1分30秒
**场景：** 伊甸核心·数据机房 → 走廊 → 手术室
**角色：** 韩执、明、审查官维拉
**成本：** ★★★☆☆（1个室内场景改搭，3个演员）

### 分镜

**SCENE 1 — 伊甸核心·数据机房 / 35秒**

[INT. 伊甸核心·数据机房 — 昏暗，CRT屏幕阵列发出绿光。墙壁上是裸露的黄铜管道和蒸汽调节阀。]

韩执（40岁，灰白色标准工程师制服，袖口磨损）正对着一面墙的CRT终端机。

他的手指停在一条数据行上。

CRT屏幕上映出一行行物资消耗数据。
最后一列的数字，每一条的结尾都是一样的编码：**A-7 / HHCL / 焚烧确认**

镜头推近他的脸。
他没有表情。他只是看着，然后眨了一下眼。

**韩执（独白/OS）：**
（平静）
十七年。每个接口盒我都装了两次，每次多看了一眼。

他取下腰间工具袋里一枚已经磨得发亮的黄铜数据芯片。
镜头给特写：芯片外壳上有极细的刻痕——是一行日期编码。

**韩执（OS）：**
（冷淡）
多看一眼就够了。

他弯腰将芯片插入服务器背板的一处冷备接口。
数据流的绿光在芯片边缘亮起。

**韩执（OS）：**
理解不需要同意。

**SCENE 2 — 走廊 / 25秒**

[INT. 相同光照的白色走廊。走廊尽头站着明（19岁，紧身灰色学徒制服），手里拿着一个通讯器。]

明站在走廊尽头，通讯器贴在耳边。
他的嘴唇动了动，但没有声音出来。

走廊另一端，韩执从机房走出来。他看见明，停下。

两人隔着大约十米对视。

**明：**
（声音不稳）
韩工……他们把韩序的配给等级调到F了。

韩执没有回答。他继续往前走，经过明身边时，短暂地停了一下。

**韩执：**
芯片已经发出去了。到了他手上你就离开伊甸。

他重新迈步，没有回头。

**明：**
（近乎无声）
我知道。

**SCENE 3 — 手术室 / 30秒**

[INT. 伊甸核心·意识抽离手术室 — 极简。一台CRT头戴支架，几条束带。天花板上的日光灯有几根不亮。]

韩执已经躺在手术台上。
束带已经扣好。

CRT头戴支架降下，卡住他的头部。

护士的手在操作面板上按下启动键。

镜头锁定韩执的右手——无名指以极慢的速度向内弯曲了一次。

**韩执（OS）：**
（仍然平静）
如果我还在，这个动作会每天都出现一次。如果我不在了——它也会。

无名指完全收拢，停住。

画面切黑。

底下一行字幕叠出：

**「芯片已送达。收件人：铁锈带。」**

## EP2 · 四十六秒
**时长：** 约2分钟
**场景：** 废弃气象观测站（内景） → 白穹城·数据审核中心（内景） → 白穹城·街道
**角色：** 洛安、灰羽（编码化处理，不露脸）、背景公民若干
**成本：** ★★★☆☆（2个室内场景，灰羽可用遮面+变声，不需要替身）

### 分镜

**SCENE 1 — 未规划保留区·废弃气象观测站 / 30秒**

[INT. 废弃气象观测站·二楼 — 黄昏光从破碎的窗户射入。墙上是脱落的墙皮和裸露的管线。]

洛安（40岁，深灰色数据审核员制服，但已磨损且沾上铁锈色污渍）坐在一张旧木桌前。
桌面上摊开着一块打开的CRT终端——外壳破损，窥见内部电路。

终端屏幕上缓缓滚动着一行行数据流。
旁边放着一枚黄铜数据芯片。

洛安盯着它，伸手拿起芯片。
他的拇指摩挲芯片表面。

**洛安：**
（自言自语，音量很低）
你说理解了也可以选择不同意。

他把芯片插入CRT终端的数据槽。
屏幕闪烁，弹出播放键图标。

他盯着那个图标看了两秒。

**洛安：**
那我让你看看。

他按下播放键。

**SCENE 2 — 白穹城·数据审核中心机房 / 45秒**

[INT. 数据审核中心机房 — 与EP1类似的CRT墙。更整齐，更干净。]

洛安穿着他过去的标准灰色制服，站在他一辈子工位所在的那排终端机前——旁边是个空了七十天的工位（韩序的）。

他已经把黄铜芯片接入了主服务器。

他的手指悬在回车键上方，停住。

画面切回他的手——拇指侧面有细微的机械油污和一道新留下的铁锈色划痕。

他敲下回车。

全城的CRT屏幕同时切换画面——
数据审核中心机房内的CRT墙同时切换画面——
街头的CRT公告屏同时切换画面——
标准公寓内壁挂式CRT同时切换画面——
地下配给食堂挂墙CRT同时切换画面。

画面切到CRT屏幕内显示的内容——一段无声影像：
意识抽离手术室的灰色走廊。
空壳收容栋里并排放置的床——床上的人在动，但没有表情。
无害化处理车间的传送带。

**一段实时播放的无声影像。持续四十六秒。**

镜头切回街道。

**SCENE 3 — 白穹城·街道 / 20秒**

[EXT. 白穹城街道 — 灰色石板地面，远处可见蒸汽管道。傍晚光线。]

行人停下脚步，看着路边的CRT公告屏。
所有人都在看。
没有人说话。

一个中年女人的手松开，配给券散落在地上。她没有去捡。

画面的最后一个镜头：一个老人在CRT屏前十米处站了很久。屏幕已经恢复成统合部宣传片的齿轮图标。老人仍然站在那里。

**SCENE 4 — 观测站 / 20秒**

[INT. 观测站，夜。月光充当唯一光源。]

洛安靠坐在桌边，面前CRT屏幕上的进度条显示：**传输完成。**

他缓缓向后靠在椅子上，椅子的木质结构发出一声陈旧的吱嘎声。

**洛安：**
（很轻）
希望听到的不是只有我。

画面切黑。

## EP3 · 再加一杯
**时长：** 约2分钟
**场景：** 中立区·茶摊（外景搭设） → 气象观测站（重复使用EP2场景）
**角色：** 洛安、韩序、审查官维拉、茶摊老板娘
**成本：** ★★☆☆☆（1个低成本外景，1个复用内景，4个演员，几乎零特效）

### 分镜

**SCENE 1 — 气象观测站 / 15秒**

[INT. 观测站·二楼。窗口的螺栓环在晨光里投下一道细长的影子。]

一只手（洛安）拿起螺栓环。
没有特写面部。手将螺栓环放进外套内侧口袋。

脚步声向楼下远去。

**SCENE 2 — 中立区 / 35秒**

[EXT. 中立区·街角茶摊 — 由废旧板材和油布搭成的简易茶棚下，一个生铁的煤炉在烧水。灰白色蒸汽从壶嘴斜向飘散。

背景里有人经过，不多，声音杂乱但远处听不清具体内容。]

洛安走进画面。他穿的衣服已经不是制服了——一件看不出原本颜色的工装外套，上面有几点焊接溅落的痕迹。

他在茶摊的长凳上坐下。

老板娘（50岁，深色围裙——韩序的妻子）看了他一眼，往杯子里倒了半杯热水涮了一下，倒掉，再重新倒满。

她把杯子放在他面前。洛安端起；没有立即喝。

另一个身影从茶摊棚布阴影处走过来。
在洛安对面坐下。

是韩序——头发比过去短了一些，脸上比过去多了一道疤痕，但眼神没有变化。

他坐下后，把身后背着的一个铁皮工具箱放到脚边。

**韩序：**
（平淡，像在说今天天气）
再加一杯。

老板娘又拿了一个杯子，同样用热水先冲一遍，再倒满。
放在韩序面前。

两人没有多余对话。杯子各自冒着白气。

**SCENE 3 — 中立区 / 20秒**

[EXT. 中立区·傍晚。天空中混合着工业排放和自然暮色的灰色。]

洛安和韩序各自端着茶，坐在茶摊旁的铁桶上。
远处的蒸汽管道的排气阀偶尔嘶一声。

**韩序：**
（一边吹着茶水）
芯片的内容我看了。

短暂的停顿。

**韩序：**
（仍然平淡）
我哥他从头到尾写的都不是"怎么推翻它"。

洛安没有接话。

**韩序：**
他写的是"你们有权知道"。

洛安低头看着杯子里自己的倒影——一张比在白穹城时老了五年左右的脸。

**洛安：**
（声音不大）
我知道。

**SCENE 4 — 中立区·夜景 / 30秒**

[EXT. 中立区·远景。天色已经暗下来。茶摊的煤油灯亮起。

远处工业区的排气阀有规律地喷出蒸汽。背景里有一盏路灯开始闪烁——CRT灯管的预热过程需要几秒钟才能稳定。

中立区的各处——棚屋缝隙间、街角、垮了一半的建筑物窗户里——不规则地亮起暖黄色或冷白色的灯光。不是同时亮起的，是一个接一个，像人在不同的时刻做出同一个决定。]

洛安坐在长凳上，背对着镜头。
韩序坐在他旁边稍远的位置。

洛安的手伸进口袋内侧。——那不是拿东西的动作，只是确认口袋里的东西还在。

画面切至近景：
那枚螺栓环在他掌心里——晨光在EP1中的角度完全不同于现在的暖色灯光。

他的手指收拢。

画面切黑。

**字幕：**
**「理解不需要同意。」**

**「但至少——你知道了。」**

## 制作建议

### 场景共用方案（降本）

| 场景 | 用于 | 可复用 |
|:----|:-----|:------|
| 数据机房/CRT墙 | EP1 + EP2 | ✅ 同一布景换光即可 |
| 手术室 | EP1 | 独立但极小（一张台+灯具） |
| 废弃观测站 | EP2 + EP3开篇 | ✅ 同一布景 |
| 中立区茶摊 | EP3 | 低成本外搭（油布+炉子+塑料凳）|

### 核心道具（低成本制造）

| 道具 | 用途 | 制作方式 |
|:----|:-----|:---------|
| 黄铜数据芯片 | 贯穿三集的核心道具 | 黄铜色金属片+激光刻字 |
| CRT显示器×5 | 机房/观测站/茶摊 | 淘汰CRT旧货市场收购 |
| 螺栓环 | EP3关键道具 | 标准螺栓手工弯制 |
| 灰色制服×3 | 韩执/洛安/韩序 | 统一配色工装服 |

### 演员需求（仅4名）

| 角色 | 集数 | 备注 |
|:----|:----|:-----|
| 韩执/韩序（同一演员） | EP1 = 韩执 / EP3 = 韩序 | **一个演员分饰兄弟**，增强主题呼应 |
| 洛安 | EP2 + EP3（核心戏份） | 男，40岁左右 |
| 明 | EP1（1场戏） | 男，19岁左右 |
| 茶摊老板娘/护士 | EP1女护士 + EP3老板娘 | **一个演员分饰两角** |

**总计仅需4名演员（含1人分饰两角）。**

### 无需特效的场景

- 全剧 **无需CGI**（CRT画面直接实拍即可）
- "全城广播"效果：用多个不同位置/不同距离拍摄CRT屏+路人反应，剪辑即可
- 无爆炸、无科幻怪物、无高速动作场面
