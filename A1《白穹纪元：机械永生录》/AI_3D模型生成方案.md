## 二、推荐策略

### 你要产出的 3D 资产清单（按用途分三层）

| 层级 | 定义 | 做法 | 工具 |
|------|------|------|------|
| **🟢 P3 - 批量资产** | 场景里的椅子、灯、管道、垃圾堆 | 全 AI 生成，不手动改 | 混元3D 本地批量跑 |
| **🟡 P2 - 标准资产** | 载具、建筑模块、道具 | AI 生成 + 简单修复 | Tripo3D / 混元3D + Blender调 |
| **🟠 P1 - 重要资产** | 核心角色、主角武器 | AI 生成作为底模 + 手动精修 | Tripo3D 出底模 → ZBrush 改 |
| **🔴 P0 - 英雄资产** | 主角洛安特写、关键场景 | **你亲手做** | ZBrush + Substance 全流程 |

### 具体分配

```
P3 批量（AI→导入即用）：废铁堆、管道、路灯、标准家具、背景NPC
P2 标准（AI→修复）：通勤列车、CRT终端、数据芯片、蒸汽锅炉
P1 重要（AI底模→精修）：铁砧工坊、伊甸手术室、信号塔
P0 亲手（ZBrush全流程）：洛安（主角特写用）、铁砧的机械义体（出彩）
```

## 三、工具使用方案

### 方案 A：混元3D 本地跑（主力，免费）

**优点：** 4090 本地跑，不限量，可商用，最适合批量出
**缺点：** 需要部署，比 Tripo3D 质量略差一点

**部署步骤：**
```
1. 去 GitHub 搜 Tencent-Hunyuan/Hunyuan3D-2
2. 按 README 安装依赖（Python + PyTorch + diffusers）
3. 下载模型权重（约 5-8GB）
4. 运行 Gradio 界面（浏览器打开，输入提示词即可生成）
5. 设置输出路径到 D:\OpenClaw专属文件夹\A1\3D_assets\
```

**本地跑 vs 在线的选择：**
- 本地跑：免费、不限量、4090 够用 → 适合批量
- 在线（混元3D官网）：免费、不用部署 → 适合试水

**提示词示例（用于混元3D）：**
```
A rusty metal gear mechanism, industrial pipe, hydraulic component,
steampunk style, damaged surface, oxidized copper texture
```

### 方案 B：Tripo3D 在线出（辅助，$19.9/月）

**优点：** 质量更好，不用自己部署，上手快
**缺点：** 要付费，免费版不可商用

**使用时机：**
- 混元3D 出不了的质量需求
- 只需要几个高质量模型的时候
- Pro 版开一个月，集中出一批然后取消

**工作流：**
```
tripo3d.ai → 图生3D（用 Stage 1 的概念图作为输入）
→ 选一张最像洛安的概念图 → 上传到 Tripo3D → 生成 3D
→ 下载 FBX → 导入 Blender/ZBrush 修拓扑 → 完成
```

## 四、分阶段执行计划

### 阶段 1：试水（1 天）

**目标：** 先用混元3D在线版跑几个道具试试水

| 任务 | 操作 | 时长 |
|------|------|------|
| 打开混元3D在线版（hunyuan3d.tencent.com） | 浏览器 | 1min |
| 上传一张"黄铜数据芯片"概念图 | 图生3D | 等1分钟 |
| 下载 GLB 文件导入 Blender 看看 | 检查拓扑和纹理 | 5min |
| 再跑一个"CRT 终端"试试 | 同上 | 5min |

**验收标准：** 跑出来一个能用的道具，拓扑不崩，纹理能看。

### 阶段 2：批量道具（1-2 天）

**目标：** 场景里需要大量填充的小模型

| 道具 | 方式 | 数量 |
|------|------|------|
| 标准金属椅 | 混元3D / Tripo3D | ×1 反复用 |
| 废铁桶 / 垃圾堆 | 混元3D 批量 | ×3-5 变体 |
| 蒸汽管道模块 | 混元3D / 自己拼 | ×2-3 段 |
| CRT 终端 | Tripo3D（质量优先） | ×1 |
| 路灯 / 信号灯 | 混元3D | ×2 |

### 阶段 3：核心角色（3-5 天）

**目标：** 8 个主要角色的 3D 底模

**做法：**
```
1. 把 Stage 1 的概念图丢进 Tripo3D → 图生3D
2. 下载 FBX → 导入 ZBrush → 修面部/机械细节
3. 减面 + 拓扑 → RizomUV → Substance Painter 重新绘贴图
4. 导出 FBX → 准备导入 UE5
```

| 角色 | 做法 | 预计时间 |
|------|------|---------|
| 洛安 | 🔴 概念图→Tripo→ZBrush全流程精修 | 2天 |
| 铁砧 | 🟠 Tripo3D 底模 → ZBrush 改机械细节 | 1.5天 |
| 韩执 | 🟠 Tripo3D 底模 → 修脑机接口 | 1天 |
| 韩序/灰羽/炎/白袍/维拉 | 🟡 Tripo3D 直出 → Blender 修小 bug | 各 0.5天 |

### 阶段 4：场景搭建（3-5 天）

**目标：** 把 AI 出的道具 + 角色拼成第一章的场景

**做法：**
```
1. 在 UE5 里新建场景 → 搭建公寓房间主体
2. 摆放 AI 出的家具道具（床、桌、CRT终端、管道）
3. 放洛安角色 → 调光照（冷白荧光灯）
4. 调音效（BGM 白穹城 + CRT 嗡鸣）
```

### 阶段 5：亲手做的英雄资产（可选）

**目标：** 做 1-2 个真正出彩的模型，证明你能做到 AI 做不到的细节

| 资产 | 理由 |
|------|------|
| 铁砧的机械义体 | 全机械结构，AI 目前做不了这种精确度 |
| 洛安（主角特写版） | 主角必须有自己的痕迹，不能是流水线脸 |
