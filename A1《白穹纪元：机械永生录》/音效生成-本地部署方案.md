# 白穹纪元 · 本地音效生成方案（4090+13900K）

> 用于生成：机械门锁、蒸汽阀门、系统提示音、环境氛围、工业音效等
> BGM仍用Suno在线生成，本方案专攻SFX

---

## 一、ComfyUI 能配合出音效吗？

**不能。** ComfyUI 是图像/视频生成工具，不支持音频生成。音效需要**另一套独立工具**。两者互不冲突，各管各的。

---

## 二、推荐方案：Stable Audio 3（本地免费）

Stability AI 最新开源的音频生成模型，有专门的 **SFX（音效）** 分支模型，最适合你的需求。

### 模型选择（你的4090建议用Medium）

| 模型 | 参数量 | 显存需求 | 最长音频 | 推荐度 |
|------|--------|---------|---------|-------|
| Small-SFX | 433M | CPU也能跑 | 120秒 | ★★★ 快速出稿 |
| **Medium** | **1.4B** | **~8GB VRAM** | **380秒** | **★★★★★ 首选** |

你的4090有24GB显存，跑Medium绰绰有余。

## 三、安装方式（两种选一个）

### 方式A：Pinokio 一键安装（推荐，最简单）

Pinokio 是一个 AI 工具浏览器启动器，点几下就装好。

**步骤：**
1. 打开 https://pinokio.computer 下载 Pinokio 安装包
2. 安装完成后打开 Pinokio
3. 搜索 → "Stable Audio 3"
4. 点击 Install → 等它下载完（模型约 2-3GB）
5. 点击 Start → 自动弹出浏览器界面

**优点：** 自动装Python、CUDA、Flash Attention，什么都不用配。

---

### 方式B：手动安装（你想折腾的话）

```powershell
# 1. 建个目录
mkdir D:\AI_Tools\stable-audio-3
cd D:\AI_Tools\stable-audio-3

# 2. 创建虚拟环境
python -m venv venv
.\venv\Scripts\activate

# 3. 克隆仓库
git clone https://github.com/Stability-AI/stable-audio-3.git
cd stable-audio-3

# 4. 安装依赖
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
pip install -r requirements.txt

# 5. 安装Flash Attention（4090必须）
# 去 https://github.com/briland/FlashAttention2Windows/releases 下载对应版本
pip install flash_attn-xxx.whl

# 6. 启动
python run_gradio.py --model medium
```

浏览器打开 http://127.0.0.1:7860 即可使用。

## 四、使用方法

打开网页界面后，你会看到：

```
[提示词输入框]  ← 在这里打字描述你要的音效
[生成按钮]      ← 点击生成
[波形预览]      ← 试听
[下载按钮]      ← 保存为 .wav / .mp3
```

## 五、你已有的ComfyUI怎么一起用

两者互不依赖，工作流是：

```
写故事/剧本
    ↓
需要配图 → 开ComfyUI → 出图
    ↓
需要音效 → 开Stable Audio 3 → 出音频
    ↓
需要BGM → 开Suno网页 → 出音乐
    ↓
后期剪辑拼接
```

各管各的，不需要联动。

## 六、白穹纪元 SFX 生产优先级

按当前项目阶段，建议先出的音效：

| 批次 | 音效 | 时长 | 用途 |
|------|------|------|------|
| **第一批** | 机械门锁、蒸汽阀门、系统提示音、CRT启动音 | 1-3秒 | UI交互基础音效 |
| **第二批** | 白穹城环境、铁锈带环境、伊甸环境 | 30秒循环 | 场景氛围 |
| **第三批** | 义体动作、步伐（金属/水泥/碎石3种）、机械仆从 | 2-5秒 | 角色动作音效 |
| **第四批** | 流放列车经过、警报声、战斗冲击 | 5-20秒 | 剧情关键音效 |

## 七、文件管理规范

生成后统一存到：
```
08-听觉音乐\generated\
├── SFX_机械门锁_20260601.wav
├── SFX_蒸汽阀门_20260601.wav
├── SFX_CRT启动音_20260601.wav
├── Env_白穹城环境_20260601.wav
└── ...
```

命名规则：`类型_描述_日期.wav`
- 类型：SFX=音效，Env=环境，UI=界面音，Act=动作
- 保留原始提示词到配套的 `音效记录.md`
