# 白穹纪元：机械永生录 · 00-体验宪法

> 本模块是整个项目的"宪法级"顶层设计文档。在做任何叙事、美术、系统、任务设计之前，都必须先通读此模块。

## 文件说明

| 文件 | 内容 |
|------|------|
| `核心情感体验.md` | 世界观的情感内核定义——"精密窒息"的无力感体验标准 |
| `美学总纲.md` | 视觉美学的总体原则和风格红线 |
| `否决项清单.md` | 设计过程中明确禁止出现的元素和行为 |

## 使用方式

1. **做设计前**：通读核心情感体验，确保创作方向与情感内核一致
2. **做设计中**：对照否决项清单，随时排查越界设计
3. **做完后**：用核心情感体验中的检验标准自我审查

> "这个设计让玩家感到更无力，还是更愤怒？"
