● 核心听觉美学

整个世界的声音体系以"机械质感"为底层音色基底。没有任何科幻合成器式的空灵效果，所有声音来自齿轮啮合、液压传动、蒸汽喷射、金属碰撞、CRT高压包嗡鸣与电子管电路的白噪声。环境音效服务于叙事与氛围营造三大区域之间的听觉差异构成了重要的"区域识别"维度。音乐不再是独立的艺术作品，而是世界观的一部分——你可以"听"出自己在哪片区域。


## 一、区域背景音乐（BGM）

◇ 白穹城 · 积分筛选区

调性：C大调为主，低音区持续的大管风琴与电子管放大器的暖音嗡鸣。节奏由远处传来的规律电流脉冲声维持（模拟脑机接口数据同步的周期信号）。中音区以黄铜管弦乐器的长音铺垫，表达秩序感与永恒的压抑宁静。

核心音色：老式CRT电视机的高压包嗡鸣声（作为环境底噪）、远距离的蒸汽管道气流声、脑机接口数据同步时规则的电子滴答声。背景中持续一个微微跑调的低频正弦波——暗示秩序之下隐藏的不完美。

听觉叙事：一切都很安静、很有规律——但安静得令人不适。积分增减时的短暂音效是这片区域最响亮的人造声。你能听到远处每个人的脑机接口同步节奏是统一的，如同同一颗心脏在跳动。

◇ 白穹城 · 工业配套区

调性：转为d小调，节拍稍微加快。加入更多的机械节奏——流水线冲压机的规律撞击声经远处传播后变钝，作为低沉的背景节奏基底。电子管失真吉他的长音在背景中游离，仿佛机器的呜咽。

核心音色：冲压机的沉重撞击（节奏声部）、远处传送带的链条摩擦声、蒸汽管道的间歇性喷涌声、金属板材的共振嗡鸣。

◇ 铁锈带 · 废弃工业带

调性：不确定调性，大量使用微分音与不和谐音程。音乐素材来自环境噪音的采集与重组——生锈铁门的铰链声采样后调速作为节奏、废金属的碰撞声叠加成节拍、风穿过废弃管道形成的空洞啸声作为旋律素材。音乐时常被环境中的真实声音打断——远处一声爆炸、一列蒸汽列车驶过的轰鸣、帮派火并的枪声。

核心音色：生锈金属的摩擦与碰撞、风穿过废弃厂房空洞的啸声、远处蒸汽列车汽笛的粗重低吼、水流滴落在铁板上的规律水滴声、齿轮卡顿时的尖啸。没有任何经过调音或处理的"干净"声音。

听觉叙事：这里从不安静，但也不算"热闹"——是一种持续的低压噪音环境，让你感觉这座城市在不断地呼吸、磨损、自我消耗。铁锈地带从不制造悦耳的声音，只有真实的生存噪音。

◇ 铁锈带 · 黑市枢纽

调性：b小调，带有爵士乐的影响——不协调的钢琴和弦与人声采样隐约浮现。比废弃工业带的噪音更有人味，但人味来自于低劣的音响设备播放着走调的录音带。

核心音色：从各个摊位漏出的混杂录音带音乐（失真走调）、机械工具的运转声、讨价还价的嘈杂人声（经过传声器后的模糊化处理）、帮派工坊里的焊接与锤击声。远处偶尔传来一台老式点唱机播放的残破旋律。

◇ 伊甸核心 · 永生者收容区

调性：沉默。伊甸核心没有传统意义上的背景音乐——风吹过空旷走廊的呜咽声是大地上唯一的旋律。偶尔从远处传来空壳住民缓慢行走的脚步声（赤足踩在金属地板上的摩擦声），或者一台老式通风机低频运转的嗡鸣。背景中存在着一个极低频的、类似于某种大型机械装置的规律颤动——那是伊甸核心地下千米深处统合部指挥中枢的运转声，以结构传声的方式扩散到整个园区。

听觉叙事：这片区域最大的声音特征是"不该有的沉默"。你可以清晰听到自己的心跳、呼吸、脚步声的回音。那种沉默是有重量的，压迫性的，告诉你这里不是供人居住的地方——这里是坟墓。


## 二、战斗音乐

◇ 普通遭遇战

以工业金属为基础，大量使用机械采样音源：齿轮啮合的节奏循环代替鼓组、气动阀门的急促开合声作为军鼓替代、蒸汽喷发的轰声作为底鼓。吉他由通过真空管前级重度失真的电子管电吉他担任，旋律线为低沉的单音riff。

◇ Boss战

分层结构：Boss战音乐随阶段推进而变化。进入第一阶段时以大型机械的节律性轰鸣作为基底——钢铁厂冲压机+蒸汽机活塞的往复运动声转化为音乐节奏。第二阶段转为急促高频——引入高压电流的噼啪声、过载变压器的嗡鸣、黄铜电路板烧毁前的尖锐啸声。最终阶段——音乐中的所有旋律元素被逐步剥离，最后只剩下一个持续稳定的低频共振（濒死机械的心跳声）和Boss本身发出的机械崩溃声与环境互动声。

◇ 统合部追杀战

以极快的机械节奏为基础——模拟扫描系统的哔哔加速声、克隆宪兵装甲关节的液压步进声、远处通讯塔发出的加密脉冲信号。音色刺耳而压迫，缺乏旋律性，像是一台无情的杀戮机器在加速运转。


## 三、UI音效

所有UI音效基于机械交互感设计，拒绝任何电子合成器效果。

◇ 基础交互类
• 按钮按下：模拟老式机械键盘的弹簧触发音 + 继电器吸合的"咔嗒"声
• 按钮弹起：继电器释放的轻微"嗒"声，带一点点机械回弹余韵
• 窗口/面板开启：模拟CRT显示器启动时的高压包充电声 + 电子管灯丝加热的嗡鸣
• 窗口关闭：显示器逐行熄灭的"嘶"声 + 继电器断开声
• 滚动/滑动：模拟电位器旋钮转动时的间歇接触声，带一点碳膜摩擦的质感
• 拖拽/放置：模拟机械卡槽锁定时的"咔哒"锁扣声

◇ 积分系统类
• 积分增加：模拟老式计算器打印纸带输出的"咔咔咔"声，积分越大音节越长
• 积分扣除：模拟机械计数器的齿轮倒转声，带一点阻尼感
• 积分不足：错误提示——模拟穿孔纸带卡纸时的急促顿挫声 + 红色指示灯亮起的"嘟"声
• 思想评分变化：脑机接口数据同步的电子脉冲声——加分时音调上浮，扣分时下沉

◇ 系统提示类
• 任务完成：电报机"滴滴答"的节拍 + 打印机的机械完成声
• 任务失败：CRT显示器故障时的闪烁跳帧声 + 继电器切断声
• 收到消息：老式电报机的滴滴声短促两响
• 警报：防空警报声的老式机械版本——旋转电机的呜咽声随转速变化
• 低血量警告：模拟心电图机的报警声——周期性的短促蜂鸣，伴随屏幕闪烁

◇ 载具交互类
• 载具发动：蒸汽锅炉点火声 + 活塞初次运动的沉重撞击 + 齿轮啮合的金属轰鸣
• 载具加速：蒸汽压力上升的嘶声 + 转速提高的齿轮高频转动声
• 载具损坏：金属疲劳断裂的撕裂声 + 液压油泄漏的喷射声


## 四、环境音效

◇ 白穹城环境层
• 持续底噪：脑机接口网络同步产生的数百万个微弱电子脉冲汇聚成一种低沉的电子嗡鸣
• 街道层：远处蒸汽地板清洁机的规律扫过声、制式机械仆从的液压步进节奏、CRT公告牌翻转刷新内容的继电器动作序列声（每整点刷新一次，约持续5秒的"咔嗒咔嗒"链条转动声）
• 室内层：墙壁内部的通风管道气流声、电力配电柜的工频嗡鸣、挂钟机械擒纵机构的规律滴答声
• 特殊：每当日落时分，全城广播统一播放统合部宣传音乐——通过街角CRT音箱播放，正式、空洞、略带失真的铜管乐进行曲

◇ 铁锈带环境层
• 持续底噪：一股低沉的、来自远处重工业园区的机械轰鸣——从未停止
• 废弃带：风吹过废铁堆时金属薄片的震颤声、锈蚀铁丝网的摇曳吱嘎声、远处的水滴入积水坑的规律回声、隔几秒一声的废旧管道内部循环蒸汽喷发声
• 黑市区：发电机组的轰鸣、各个黑市摊位传来的混叠的走调收音机音声、铁匠铺的锤击节奏、讨价还价的浑浊人声、偶尔的枪声或爆炸声
• 夜间的铁锈带：工业机械噪声下降后，能听到一种低频的、类似金属疲劳的"咔咔"声——那是废铁堆由于白天受热膨胀后夜间冷却收缩发出的声音。它听起来像是这片废土在低声呻吟

◇ 伊甸核心环境层
• 持续底噪：几乎为——零。没有电子设备的声音，没有机器运转声，没有通风系统的气流声
• 室外：风声——吹过空旷的制式建筑群时，在走廊与庭院之间形成空洞的呼啸。空壳住民整齐划一的缓慢脚步声（数十人同步行走的赤足摩擦声，异样的整齐）。偶尔有一台被忽略的空调外机远远运转
• 室内：自己的心跳声被室内的安静放大呈背景节奏。呼吸声被空间的空旷反射成细微的回音。墙壁内偶然传来的巨大低频嗡鸣——来自地下千米深的统合部指挥中枢，大约每隔30秒一次
• 特殊：清理周期启动时，园区内响起一种低频的、可穿透墙壁的警报信号，伴随地下机关启动的轰鸣声——那是无害化处理设施运转的声音


## 五、角色音效

所有角色的音效应基于其义体改造程度与种族身份差异化设计。

◇ 步伐类
• 纯血统合者：基本无声——皮鞋踩在抛光地板上发出轻微的共振，被随从的脚步声掩盖
• 神经接驳者：靴底硬质后跟落在金属地面上发出规律的"咔、咔"声，偶尔伴随背部CRT终端内部的磁盘转动声
• 克隆宪兵：沉重——液压装甲关节每次迈步都发出气动阀门泄压的"嗤"声，钢制装甲底板撞击地面发出沉闷的金属撞击声
• 积分公民：统一制式皮鞋的整齐脚步声—统一、整齐、毫不出格
• 拾荒游牧民：布条与废料制成的鞋底发出的擦刮声，腰间悬挂的齿轮零件互相碰撞的叮当声
• 废铁机械师：不对称的步态节奏—由于义体重量的差异，走路时偏重的一侧步幅略沉；机械义肢关节处发出机油不足时的轻微摩擦声
• 空壳永生者：赤足摩擦在磨砂地面上的连续擦刮声，没有节奏变化，如同受同一信号控制的同步运动
• 觉醒者：赤足的蹒跚脚步，偶尔因虚弱而滑倒；病号服布料的摩擦声

◇ 义体动作类
• 机械手臂举起/放下：液压管路的油液流动声 + 齿轮啮合的短暂咔哒
• 拳头紧握：五指关节的钢制液压传动声 + 伺服电机微调的嗡鸣
• 腿部义体高抬/踢击：大功率液压活塞伸出的"嗤——砰"两声（充气+撞击）
• 头部神经接口拔插：拔出时的真空破坏声（类似拔香槟塞） + 插入时的锁定咔嗒
• CRT义眼调焦：内部纯机械对焦环的转动声 + 微弱的阴极管电荷变化声
• 全身义体过载散热：所有散热格栅同时弹开的"呲——"声，热气涌出，继电器快速通断的咔嗒声阵

◇ 机械仆从类
• 行走：小型内燃机规律运转的突突声 + 轮式底座碾压地面的摩擦声
• 动作：机械臂各关节伺服电机的协调嗡鸣 + 夹爪闭合时的齿轮啮合声
• 待机：发动机怠速的低频震颤 + 内部散热风扇的规律旋转声
