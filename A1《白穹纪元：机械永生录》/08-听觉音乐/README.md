## 核心音色

- 电子管合成器（白穹城：规律/均匀；伊甸：空灵/空洞；铁锈带：粗糙/不规则）
- 金属打击乐（齿轮啮合、蒸汽阀门、管壁谐振）
- 环境采样（CRT嗡鸣、焊接电弧、中波静电）
- 无管弦乐、无人声哼唱、无自然采样
