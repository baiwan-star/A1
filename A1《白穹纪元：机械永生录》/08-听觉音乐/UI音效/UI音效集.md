# UI音效集

所有UI音效基于机械交互感设计，拒绝任何电子合成器效果。

## 基础交互类
- **按钮按下**：老式机械键盘弹簧触发音 + 继电器吸合"咔嗒"声
- **按钮弹起**：继电器释放轻微"嗒"声，带机械回弹余韵
- **窗口/面板开启**：CRT显示器启动时高压包充电声 + 电子管灯丝加热嗡鸣
- **窗口关闭**：显示器逐行熄灭"嘶"声 + 继电器断开声
- **滚动/滑动**：电位器旋钮转动间歇接触声，带碳膜摩擦质感
- **拖拽/放置**：机械卡槽锁定"咔哒"锁扣声

## 积分系统类
- **积分增加**：老式计算器打印纸带输出"咔咔咔"声，积分越大音节越长
- **积分扣除**：机械计数器齿轮倒转声，带阻尼感
- **积分不足**：穿孔纸带卡纸急促顿挫声 + 红色指示灯亮起"嘟"声
- **思想评分变化**：脑机接口数据同步电子脉冲声——加分时音调上浮，扣分时下沉

## 系统提示类
- **任务完成**：电报机"滴滴答"节拍 + 打印机机械完成声
- **任务失败**：CRT显示器故障闪烁跳帧声 + 继电器切断声
- **收到消息**：老式电报机滴滴声短促两响
- **警报**：防空警报机械版本——旋转电机呜咽声随转速变化
- **低血量警告**：心电图机报警声——周期性短促蜂鸣，伴随屏幕闪烁

## 载具交互类
- **载具发动**：蒸汽锅炉点火声 + 活塞初次运动沉重撞击 + 齿轮啮合金属轰鸣
- **载具加速**：蒸汽压力上升嘶声 + 转速提高的齿轮高频转动声
- **载具损坏**：金属疲劳断裂撕裂声 + 液压油泄漏喷射声
